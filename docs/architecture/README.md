# Architecture Documentation

Architecture decisions, cost models, deployment designs, and ADRs belong here. The current contents are proposals for the Human Architecture / Data Integration Checkpoint; they are not implementation authorization.

## Proposed documents

- `ARCHITECTURE.md` - recommended solution, application boundaries, scale path, risks, and evidence.
- `COST-MODEL.md` - MVP scenarios, Canadian-region cost assumptions, and FinOps guardrails.
- `ARCHITECTURE-DATA-RECONCILIATION.md` - cross-track decisions and unresolved conflicts.
- `adr/ADR-001` through `adr/ADR-009` - proposed technology and delivery decisions.

No source code, infrastructure, migrations, or deployment pipeline is part of this phase.
