# Architecture Documentation

Architecture decisions, cost models, deployment designs, and ADRs belong here. The architecture and ADRs are approved by the Human Architecture / Data Integration Checkpoint; merchant-specific connector work remains gated by the integration policy documents.

## Approved documents

- `ARCHITECTURE.md` - recommended solution, application boundaries, scale path, risks, and evidence.
- `COST-MODEL.md` - MVP scenarios, Canadian-region cost assumptions, and FinOps guardrails.
- `ARCHITECTURE-DATA-RECONCILIATION.md` - cross-track decisions and unresolved conflicts.
- `adr/ADR-001` through `adr/ADR-009` - proposed technology and delivery decisions.

Application foundation, local infrastructure, migrations, and connector-neutral fixtures are now authorized. Production infrastructure and merchant-specific connectors remain separately gated.
