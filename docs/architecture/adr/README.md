# Architecture Decision Records

Proposed and approved architecture decisions belong in this directory. Every ADR must state its checkpoint status and use the format: Context, Options, Decision, Reasoning, Tradeoffs, and Migration Path.

ADR-001 through ADR-009 are **APPROVED - Human Architecture / Data Integration Checkpoint**. ADR-010 records the owner's explicit provider-specific handoff decision. ADR-011 records the owner's controlled Amazon short-link resolution refinement. ADR-012 records confirmed Brand-candidate intake with normalized identity and transactional offer save. ADR-013 records a future Google end-user sign-in proposal and is **PROPOSED — NOT APPROVED FOR IMPLEMENTATION**. ADR-014 records the approved individual-offer pricing, routing, discovery, and Wishlist identity. Approval authorizes implementation only within approved records and does not authorize ADR-013, unverified merchant connectors, or Product-data rights.
