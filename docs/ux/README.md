# UX Documentation

The UX phase is based on the approved Product Checkpoint and is awaiting the Human UX Checkpoint.

- [`UX-RESEARCH.md`](UX-RESEARCH.md) — live pattern research and benchmark synthesis.
- [`UX-DESIGN.md`](UX-DESIGN.md) — UX source of truth and interaction decisions.
- [`WIREFRAMES.md`](WIREFRAMES.md) — responsive text wireframes and state annotations.
- [`DESIGN-SYSTEM.md`](DESIGN-SYSTEM.md) — proposed visual language and component behavior.
- [`UX-BACKLOG.md`](UX-BACKLOG.md) — prioritized UX stories and acceptance criteria.

These documents intentionally do not select technology, define integrations, or create application code.
